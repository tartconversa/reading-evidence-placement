# 阅读素养证据的诊断分组与支持接续

合成资料驱动的本地诊断应用：教研员分次导入各校作答、评分、在读关系与支持课程资料，
系统按**校内演练口径**产出可解释的分维度判断，教师据此在有限名额内安排支持。
所有人员、学校与记录均为合成编号；维度名称、关注线与判定规则**不声称复现国家标准的完整细则**。

## 边界与口径（先读）

- 三个维度：`knowledge` 阅读知识、`understanding` 文本理解、`reflection` 反思评价，**永不合并成一个总等级**。
- 一次缺考（`score=null, missing_reason=absent`）不计零、不算能力证据，只作为缺失原因呈现。
- 不同测评的题目与满分尺度不同；跨测评只在**教研员批准且未撤回**的共同题（anchor）联系下，
  按锚题**得分率**比较，不做分数等值假设；没有有效联系的两次得分不能计算进步幅度。
- 判断分五类：证据不足 `insufficient_evidence`、当前偏弱 `current_weakness`、
  持续困难 `persistent_difficulty`、已有改善 `improved`、表现稳定 `maintained`。
- 测量不确定性用 Wilson 95% 区间表达，题量越少区间越宽；区间随诊断一并展示。
- 群体比较按**测评当日在读关系**定分母：转校生当日只属于新校，缺考者仍留分母，
  补交成绩不会把未参加者从分母中抹去。
- 自动建议（`system`）与教师确认（`teacher/import`）分账记录；候补是系统裁决，不等于确认。
- 已实际参加的课程是既成事实，任何更正、撤回或重传都不能撤销成未发生。

## 运行

仅使用 Python 3.11 标准库，无第三方依赖。资料目录通过参数传入，不进入 `sys.path`：

```sh
python3 -I run_reading.py --db state/reading.sqlite3 import materials
python3 -I -m unittest discover -s tests -v
```

`-I` 隔离环境路径，避免资料目录中的同名模块被导入。状态库默认在 `state/`（已 gitignore），
原始 `materials/` 永不被应用改写。

## 本地操作入口

| 命令 | 角色 | 作用 |
| --- | --- | --- |
| `import <资料目录>` | 教研员 | 校验契约后整包导入，可反复执行；人工撤回与已发生事实受保护，冲突写入回执 |
| `batches` | 教研员 | 导入批次、资料指纹与行数 |
| `approvals [--all]` | 教研员 | 查看比较批准及撤回状态 |
| `withdraw-approval <L编号>` | 教研员 | 撤回联系，受影响的未开始确认被标记**待复议**并生成影响事件 |
| `diagnose <学生编号>` | 教师/教研员 | 分维度判断、证据覆盖、不确定性、阻断的比较与原因 |
| `group <测评编号>` | 教研员 | 按当日在读构成的各校分母、参与、缺考与维度得分率 |
| `plan` | 系统 | 重算建议、候补（持久化序号）与补充观察；容量与重叠时段强约束 |
| `accept/adjust/defer/cancel <请求>` | 教师 | 接受、调整确认、暂缓或撤销（撤销仅限未开始） |
| `promote <请求>` | 教师 | 名额腾出后按候补队首递补，不可插队 |
| `requests [--person --course]` | 教师 | 席位台账，含状态、来源、复议标记与出勤 |
| `attend <请求> [--absent]` | 教师 | 回录课程实际发生；只允许追加，不能回退已发生事实 |
| `observations [--person]` / `complete-observation <id>` | 教师 | 证据不足学生的补充观察任务与完成回录 |
| `impacts [--all]` / `ack-impact <id>` | 教师/教研员 | 更正/撤回影响了哪些在办安排，及知悉登记 |
| `explain <请求>` | 教师 | 追问一次建议采用的测评、批准编号与当时口径快照 |
| `audit [--request <请求>]` | 教研员 | 全部操作或单条安排的审计轨迹 |

请求可用自增编号，或 `学生编号:课程编号` 定位。所有写命令支持 `--actor` 与 `--on`，
加 `--json` 输出机读结果。

## 判定规则摘要

阈值全部来自资料中的 `observation_policy`（每维度一条），诊断结果内嵌当时口径快照：

1. 维度有效题数 `< min_items` 的测评不计为有效观察（整卷缺考自然被排除）。
2. 有效观察不足 `minimum_observations` 次 → **证据不足**，只生成补充观察，不进入课程候选。
3. 得分率 `< concern_ratio` 记一次偏弱；偏弱次数达到 `minimum_observations` → **持续困难**。
4. 曾多次偏弱但最近观察回到关注线上，且有效批准下锚题得分率回升 → **已有改善**。
5. 知识与理解方向相反时，`divergence` 字段同时保留两个结论，不压成单一等级。

## 名额与候补

- 课程按维度、学段、时段、容量开放；同一学生在重叠时段不能占两席（系统与教师两侧都强校验）。
- 候补优先级：持续困难且未获同维度支持 > 当前偏弱 > 持续困难但已有支持 > 已有改善；
  候补序号持久化，只能队首递补。
- 证据不足的学生只安排补充观察，**不会为填满课程被归为低能力**。
- 评分更正或联系撤回后：诊断与候补资格按新证据重判；已确认未开始的安排只标 `review_flag`
  提示教师复议，名额不被静默腾出；已参加课程不受影响。
- 新一轮观察导入后重新规划：结课不自动等于困难消失，后续资格依据新证据决定，课程历史保留。

## 代码结构

```
reading_app/
  models.py   领域常量、判断枚举与数据结构
  store.py    SQLite 状态库：资料镜像、席位台账、补充观察、影响事件、审计
  domain.py   观察汇总、Wilson 不确定性、分维度判断、进步口径、群体分母、复议重判
  planner.py  建议生成、容量裁决、候补队列与补充观察
  cli.py      本地命令行入口
tests/        资料契约、诊断、工作流与 CLI 端到端测试（含转校×更正×已确认名额相遇）
run_reading.py  -I 启动器
```
